# Projeto Calculadora Python
Projeto inicial com conceitos básicos de Python.


## calculadora.sh
Para executar o arquivo "calculadora.sh", no windows, siga as seguintes etapas:
1.  abra o Prompt de Comando (cmd) ou PowerShell como Administrador.
2.  digite o comando "wsl --install".
3.  abra o terminal da sua distribuição Linux.
4.  acesse a pasta onde o arquivo "calculadora.sh" está através do terminal.
5.  dê a permissão de execução do arquivo com o comando "chmod +x calculadora.sh"
6.  execute o script através do comando "./calculadora.sh".

## calculadora.ipynb
- Código Python de uma calculadora simples que realiza operações básicas (soma, subtração, multiplicação e divisão) com dois números fornecidos pelo usuário.
